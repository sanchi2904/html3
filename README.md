# 💖 Barbie Movie Webpage

## 📌 Project Overview
This project is a **Barbie-themed movie webpage** developed using **HTML and CSS**. The webpage is designed to showcase Barbie movie content with attractive visuals, styling, and a user-friendly interface.

The project includes images and design elements inspired by Barbie movies to create an engaging and aesthetic webpage experience.

---

## 📂 Project Files

### 1. `index.html`
The main webpage file containing:
- Webpage structure
- Content layout
- Movie-related sections
- Image integration

### 2. `style.css`
The stylesheet file responsible for:
- Page styling
- Colors and themes
- Layout formatting
- Responsive appearance

### 3. `arnika.png`
Image asset used in the webpage for visual design and movie-related content.

### 4. `diamondcastle.png`
Image asset used for Barbie movie visuals and webpage enhancement.

---

## 🛠️ Technologies Used
- **HTML5** – Webpage structure  
- **CSS3** – Styling and design  

---

## 🚀 How to Run the Project

### Method 1: Open Directly
1. Download or clone the repository.
2. Open the project folder.
3. Double-click the `index.html` file to open it in your browser.

### Method 2: Using VS Code
1. Open the project folder in **VS Code**.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Click **"Open with Live Server"**.
